## Professional Summary
This repository serves as a comprehensive collection of practice exercises and projects developed during the completion of the Google IT Automation with Python Professional Certificate. It demonstrates hands-on experience in automating system administration tasks, managing IT infrastructure, and developing scalable scripts using Python.

## 🛠️ Core Competencies Demonstrated
- **Python Scripting**: Automating file operations, data manipulation, and system processes.
- **Git/GitHub Version Control**: Efficient branch management and collaborative workflows.
- **System Administration**: Managing local and remote systems through automated configuration.
- **Configuration Management**: Utilizing automation to maintain consistent infrastructure.
- **Troubleshooting & Debugging**: Implementing logical workflows to identify and resolve system issues.

## 📂 Project Structure & Features
The project is organized by course modules to illustrate progressive skill development:
- `Course3/`: Introduction to basic automation scripts.
- `Course4/`: Advanced system troubleshooting and automation techniques.
- `Course5/`: Configuration management and infrastructure as code basics.
- `docs/`: Technical documentation and supplementary resources.

## 🚀 Getting Started
1. **Clone the repository**: `git clone https://github.com/MarkAngelGuevarra/it-cert-automation-practice.git`
2. **Setup your environment**: Ensure you have Python installed.
3. **Explore modules**: Navigate into specific `Course` directories to view scripts and documentation.
